# EvoMachine user guide

[Documentation](../README.md) › User guide

This guide is for microscope operators and experiment authors.

1. Read the [system overview](overview.md) for lifecycle and terminology.
2. Follow [Using the GUI](gui.md) for acquisition and focus workflows.
3. Use [Virtual mode](virtual-mode.md) before running a new hardware workflow.
4. Follow [Writing and running strategies](strategies.md) for Python or AutoStrat.
5. Consult [Failures, logs, and troubleshooting](troubleshooting.md) when an
   operation stops or a device fails.

The GUI does not make unsafe experimental values safe. Confirm stage limits,
illumination, exposure, DMD calibration, and focus behavior on the physical
microscope before enabling hardware.
